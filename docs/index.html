まいにちZINE作例A4 1枚・8ページの本をつくる

いま作っている8ページを消して、まっさらにします。

えらんだ写真で8ページを作りなおします。いま作っている8ページは消えます。

あなたの1冊を作ってみよう！

なにの本にする？　えらぶと表紙のタイトルが入ります（あとで書きかえられます）。

  1. 写真を8枚までえらぶ → 表紙から順に1ページに1枚ずつ入る
  2. ページごとに「ひながた」をえらび、写真や文字を指で動かして整える
  3. 「A4 にする」で1枚に並べて、刷って、折る

下にあるのは作例「にしむ〜の好きな動画集」。好きな動画は「＋動画・QR」で、サムネイルと QR を置けます。

指でドラッグして動かす・2本指で広げて拡大

ひながた

いろ

写真はこの端末の中だけで使います。どこにも送りません（「＋動画・QR」で貼った URL だけは、サムネイルとタイトルを YouTube に取りに行きます）。顔・名札・制服・学校名は写さないでね。

できあがり

この1枚を印刷して、折って、真ん中を1本切ると本になります。

刷り方をえらぶ

印刷するとき：PDF を「実際のサイズ（100%）」で印刷してください。「用紙に合わせる」だと少し縮んで、折り目がずれます。
保存ボタンが動かないときは、上の画像を長押しして保存できます。
  1. 印刷した面を外にして、横長のまま上下に半分に折って開く
  2. 左右に半分、さらに半分に折って、8マスの折り目をつける
  3. 上下に半分に折ったまま、真ん中の2マスぶん（破線）だけ切る
  4. 開いて両端を押し寄せ、十字になったら表紙が外に来るようにたたむ
