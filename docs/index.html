この1枚を印刷して、折って、真ん中を1本切ると本になります。

印刷するとき：PDF を「実際のサイズ（100%）」で印刷してください。「用紙に合わせる」だと少し縮んで、折り目がずれます。
保存ボタンが動かないときは、上の画像を長押しして保存できます。
  1. 印刷した面を外にして、横長のまま上下に半分に折って開く
  2. 左右に半分、さらに半分に折って、8マスの折り目をつける
  3. 上下に半分に折ったまま、真ん中の2マスぶん（破線）だけ切る
  4. 開いて両端を押し寄せ、十字になったら表紙が外に来るようにたたむ
